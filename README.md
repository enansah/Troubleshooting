Troubleshooting concept 
Troubleshooting is the process of identifying problems and solving them 
Debugging is the process of identyfying, analysizing and removing bugs of a system.

Difference 
Troubleshooting means fixing problems in the system running the application whilst debugging is fixing the bugs in the code of the application.

Problem solving steps 
1.Gather information
2.Fiinding the root course of the problem
3.Perform the necessary remediation to prevent problem from happening again.
