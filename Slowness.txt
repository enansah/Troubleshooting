//Parallelizing operation(Concurrency)
Threads let us run parallel tasks inside a process.
Parallelizing could be a wrong solution for other programs since it could create bottlenecks.

In Python, we can use the Threading or AsyncIO modules to ​do this. These modules let us specify which parts of the code we want to run ​in separate 
threads or as separate asynchronous events, and how we want the ​results of each to be combined in the end.

A script is CPU bound if you are running operations in parallel using all available CPU time.  

There is no need for a cloud storage data that is to be store is not huge since it could reduce the runtime of the program.

Futures is the module that makes it possible to run operations in a script in parallel that makes better use of CPU processing time.
Syntax:
Executor = future.ThreadPoolExecutor - this is to create threads for programs
Executor = future.ProcessPoolExecutor - this is to make process run concurrently using all cores
